## 2025-02-23 - [Optimize NumPy Top-K Selection with argpartition]
**Learning:** `np.argsort` has O(N log N) complexity, causing performance bottlenecks during top-K candidate selection in large vector search indices (e.g., K3 MRL Indexer). For top-K selection without a full sort, `np.argpartition` provides O(N) complexity. In benchmarks, switching from `argsort` to `argpartition` for K=75 out of 100,000 vectors reduced the execution time from ~4.0ms down to ~0.36ms (a 10x+ improvement).
**Action:** When extracting top-K candidates from large NumPy arrays (e.g., scoring matrices, similarity calculations), always prioritize `np.argpartition` followed by sorting just the selected partition, rather than using `np.argsort` on the entire array.

## 2025-02-23 - [Optimize String Operations and NumPy Norms]
**Learning:** During large-scale file system traversal, replacing `pathlib.Path(file).suffix in extensions` with native string methods like `file.endswith(ext_tuple)` avoids expensive object instantiation inside tight loops (yields ~20x speedup). Additionally, calculating 1D squared norms in NumPy using `np.einsum('ij,ij->i', A, A)` instead of `np.linalg.norm` avoids intermediate array creation and is significantly faster (~3-4x).
**Action:** Always prefer native string matching operations in hot loops over object instantiation (like `Path`). For fast Euclidean norms in NumPy without `np.linalg.norm` overhead, use `np.sqrt(np.einsum('ij,ij->i', A, A))[:, np.newaxis]` for 2D matrices and `np.sqrt(np.dot(v, v))` for 1D vectors.
