## 2025-02-23 - [Optimize NumPy Top-K Selection with argpartition]
**Learning:** `np.argsort` has O(N log N) complexity, causing performance bottlenecks during top-K candidate selection in large vector search indices (e.g., K3 MRL Indexer). For top-K selection without a full sort, `np.argpartition` provides O(N) complexity. In benchmarks, switching from `argsort` to `argpartition` for K=75 out of 100,000 vectors reduced the execution time from ~4.0ms down to ~0.36ms (a 10x+ improvement).
**Action:** When extracting top-K candidates from large NumPy arrays (e.g., scoring matrices, similarity calculations), always prioritize `np.argpartition` followed by sorting just the selected partition, rather than using `np.argsort` on the entire array.
## 2025-02-23 - [Optimize os.walk File Extension Checks]
**Learning:** Instantiating `pathlib.Path(file).suffix` inside the inner loop of `os.walk` to check file extensions is extremely expensive and causes massive overhead when scanning large directories like `node_modules` (if not properly skipped) or even standard file trees. In benchmarking, simply switching from `Path(file).suffix in extensions_set` to `file.endswith(extensions_tuple)` yielded a 2.36x+ speedup for file scanning.
**Action:** When performing large-scale file system traversals (e.g., using `os.walk`), always prefer native string methods like `file.endswith(ext_tuple)` over instantiating new objects like `pathlib.Path` in the tightest inner loop.

## 2025-02-23 - [Optimize Cosine Similarity Normalization with einsum]
**Learning:** During vector search scoring, computing the fully normalized intermediate matrix via `matrix / np.linalg.norm(matrix, axis=1, keepdims=True)` is slower than computing 1D squared norms first via `np.einsum('ij,ij->i', matrix, matrix)` and taking the square root. Benchmarks show a ~1.67x speedup for this specific normalization math, which becomes significant when reranking thousands of candidates in the hot path.
**Action:** Whenever normalizing an NxD matrix for cosine similarity in a hot path, consider pre-computing squared norms via `np.einsum` to avoid the overhead of `np.linalg.norm` and full matrix allocations.
